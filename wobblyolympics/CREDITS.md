# WOBBLY OLYMPICS - credits

Everything you see and hear is made in code inside `wobblyolympics.html`: the stadium, crowd, athletes, hats, flags,
pictograms, props, particles, the synthesised sound effects, the menu tune and the kazoo anthems. No image, model or
audio files are used.

External libraries and fonts loaded at runtime:

- **three.js r128** - 3D rendering. MIT License, (c) 2010-2021 three.js authors. Loaded from cdnjs.
- **Lilita One** (Juan Montoreano) and **Nunito** (Vernon Adams, Cyreal, Jacques Le Bailly) - SIL Open Font License 1.1, via Google Fonts.

All nations, athletes and records in the game are made up. The game does not use the Olympic rings or any real
organisation's logo, mascot or athlete.
