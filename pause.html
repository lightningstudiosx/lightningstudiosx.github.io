The Game of Pausing

a normal little arcade game — except it refuses to be paused. press Escape, hit Print Screen, tab away, open the snipping tool, even let your mouse leave the window… and every pixel turns to static. nothing to see. nothing to screenshot. the game only exists while you're playing it.

somewhere in the game a secret code scrolls by. you can only read it live.
