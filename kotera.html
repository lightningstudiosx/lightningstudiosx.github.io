The turning script

Each row is one consonant. Its four symbols are the same shape turned: it points down for e, up for i, right for o and left for a. The last column is the small raised final, a consonant with no vowel. Tap any symbol to hear it.

Count in twelves

Kotera digits are clock faces: twelve o'clock is zero, so each digit runs 0 to 11. Read a number as gross (144s), dozens (12s), then ones.

The twelve digits

12 is fal (a dozen) and 144 is mor (a gross).
